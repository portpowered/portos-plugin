# Thermostat and current indoor temperature

For "lower the temperature" or "what's the temperature right now?", determine whether the user means indoor/device temperature or outdoor weather. If context does not decide, ask which; do not silently substitute weather for a connected-home reading.

1. Make one focused endpoint_query for the intended room/name or thermostat and temperature-sensor capabilities, with expand:["thermostat","temperature-sensor","connectivity"] and forceDeviceAttributeQuery:true. Follow pagination when needed. The same response supplies identity, declarations and observations; do not enumerate unrelated devices or immediately read the selected endpoint again. Keep accounts' IDs separate, and clarify if several thermostats match.
2. Current temperature is the temperature-sensor ambient reading, never a target setpoint. Report FRESH observations and units as current. STALE values are last known: include sampledAt. Errored or missing readings are unknown; do not infer a temperature from mode, a target or weather.
3. For control, reuse the selected exact endpointId and its declared command. `thermostat/set-target-temperature` takes {"targetSetpoint":{"value":21,"scale":"CELSIUS"}} (or lowerSetpoint and upperSetpoint for a range thermostat). Scale is exactly CELSIUS or FAHRENHEIT and value is numeric. A relative change uses the FRESH current setpoint from step 1, not ambient temperature; ask for an explicit target when it is missing. Do not substitute a different device for an unsupported fan or mode.
4. Send once. Ordinary absolute commands use waitForResult:false: acknowledge acceptance without claiming a changed physical state. For requested verification, make one fresh query of the same endpoint and relevant expansions, then compare observations. A changed target does not mean the room has reached that temperature. Never automatically repeat an uncertain change. Open endpoint_show only when the customer asks for a card or controls.

Preserve the requested units where supported. Providers can quantize a setpoint to their native step: 70°F is about 21.11°C, so a 0.5°C device can report 21°C. Display the actual returned setpoint and units rather than an exact requested value the device did not report.

To show a thermostat so a specific card leads, call endpoint_show with the exact endpointId and primary set to one of its cardIds: "turn the thermostat fan on" uses primary:"fan" (then send the declared fan command with control), "how open are the blinds" uses primary:"closure". Without primary the device's usual card leads; every other card stays behind the details toggle.
