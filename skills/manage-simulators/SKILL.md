# Manage simulator devices

Test device control without physical hardware. Sign in to Port OS before you start.

## Create a simulator

1. Open [Simulators](https://portoperatingsystem.com/simulators/).
2. Select **New Simulator**.
3. Choose a light and give it a clear name.
4. Create it, then open its linked endpoint from [Your Devices](https://portoperatingsystem.com/dashboard/).

## Control the device

Use the endpoint power control to turn the light on or off. Read its returned power value to check the result. A simulated vacuum comes with rooms (Living room, Kitchen, Bedroom, Hallway unless you list your own) that you can clean one by one with clean-room. You can also use the simulator endpoint in the [Quick start](https://portoperatingsystem.com/docs/getting-started/) or connect an [AI client](https://portoperatingsystem.com/connect-ai/).

## Edit or remove a simulator

Open the simulator from the list. Use its edit or delete control. Removing a simulator removes your test device; confirm the selected device before deleting it.

If a simulator does not appear, refresh the list and confirm you are signed in to the same account. If a command fails, check endpoint permissions and try again after the pending command completes.
